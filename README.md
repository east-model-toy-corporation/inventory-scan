# 條碼盤點

手機或電腦都可使用。支援手機相機連續刷讀、USB／藍牙掃描槍、手動批次輸入、Excel／CSV 商品主檔、離線暫存，以及透過 Google 試算表跨裝置彙總。

1. 在「設定開始」選擇門市並填寫盤點人，區域／貨架可選填。有進行中的場次時會自動加入，並沿用該場次的模式。建立新場次時可選擇模式並匯入 Excel／CSV。有主檔模式的場次若尚無主檔，加入者也可匯入。雲端主檔會在同門市、同場次的裝置間共享。
2. 在「刷讀」開啟鏡頭，或將條碼輸入後按 Enter。「數量」可指定下一次刷讀的件數，計入後會回到 1。最近刷讀卡可直接修改該筆總數，也可用 −、＋、+5、+10、+12 快速調整。輸入總數時會暫停辨識，確認後繼續掃描。有主檔模式若查無條碼，可依品名、條碼或貨號搜尋，或選擇直接計入、取消。刷讀時可按頁首的「區域」按鈕切換或清除區域，之後的刷讀會依新區域累計。
3. 在「彙總」重新整理全場資料，並匯出 Excel（彙總、明細、依人員、依區域）或 CSV。在「設定」可下載本機 JSON 備份。
4. 跨裝置盤點時，各裝置使用相同的 API 網址與金鑰，再選擇同一門市。GitHub Pages 版已預設 API 網址，「設定」中的網址留空即可使用預設值。場次以門市及台北開始日期命名，跨日會沿用原場次。按「結束盤點」後，再選該門市就會開新場次。上一場仍可從「彙總」查看和匯出。
5. 設定雲端後，離線時可繼續本機已快取的進行中場次。離線確認結束後，結束指令會在恢復連線時同步。若場次已被結束而明細未能上傳，可按「匯出本機備份」保留明細。未設定雲端時，各門市的場次由此裝置管理。

主管可用設定連結 `https://<帳號>.github.io/inventory-scan/#key=<API金鑰>` 協助同仁完成設定。使用其他 API 時，可加上 `&url=<API網址>`。金鑰與網址都應經過 URL 編碼。請透過 LINE 私訊等私人管道分享金鑰或設定連結，切勿提交到 Git。

離線時資料會先保存在本機。設定雲端連線後，待上傳資料會在連線恢復時自動重試。首次開啟需要連線，以便快取應用程式供離線重新載入使用。

「刷讀明細」欄位依序為 時間｜場次｜門市｜盤點人｜區域｜裝置｜條碼｜品名｜數量｜id｜更新時間｜狀態。空白區域在「依區域」彙總顯示為「未填區域」。

## POS 主檔格式

在「設定開始」選擇「有商品主檔（對照帳面）」後，可匯入 POS 的「庫存明細查詢(明細)」Excel 檔（`.xls` BIFF8 或 `.xlsx`），也可匯入一般 Excel／CSV 主檔。系統在第一個工作表的前 20 列尋找表頭，略過空白資料列及條碼欄為「合計」、「總計」或「小計」的列。

| 用途 | 可辨識的欄名 |
| --- | --- |
| 條碼 | 商品型號、型號、商品條碼、條碼、國際條碼、barcode、jan、ean |
| 品名 | 品名規格、品名、商品名稱、name |
| 帳面數量 | 合計、庫存量、庫存、帳面數量、帳面、數量、qty |
| 選填欄位 | 貨號（sku）、單價、庫點、架號 |

有多個符合的欄名時取第一欄。條碼以文字處理，保留前導零。重複條碼以最後一列為準。匯入後可查看庫點、負庫存與重複條碼。庫點與所選門市不符時會顯示提醒，仍可開始盤點。

刷讀原條碼時，若主檔只有一筆帶後綴的對應商品，系統會以該商品的完整條碼計入。若有多筆對應商品，或原條碼與帶後綴的商品同時存在，請在清單中選擇商品、直接計入原條碼或取消。

## 開發與測試

- `node --test tests/` 或 `npm run test:gas` 執行 Node.js 測試。
- `node --test tests/gas.test.js` 單獨執行 Apps Script 測試。
- `npm run fixtures` 產生合成 POS 與相機測試檔。
- `npm run test:e2e` 執行 Playwright 測試（相機介面測試只在 Chromium 執行）。
- `npm test` 依序執行 Node.js 和 Playwright 的完整測試。
- `npm run serve` 啟動前端和模擬 API，並印出兩個網址。測試 API 金鑰為 `test-key`。

螢幕截圖儲存在 [screens/](screens/)。執行 `npx playwright test tests/screens.spec.js --project=webkit` 可重拍九張 iPhone 14 介面截圖，包含「結束盤點」、主檔查無提示和品名搜尋。執行 `npx playwright test tests/camera.spec.js --project=chromium-camera` 可重拍 ZXing 辨識條碼後的 `07-camera-scan.png` 與 `09-quick-qty.png`。執行 `npx playwright test tests/compact.spec.js --project=chromium-camera` 可重拍三種手機尺寸的緊湊版面（12–14）。
